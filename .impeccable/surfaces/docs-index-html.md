# Surface: Linemark homepage (docs/index.html, published to ey4o.github.io/linemark-site/)

Mode: Persuade. Audience: people deciding whether to install Linemark, plus Google's OAuth brand-verification reviewers. Job: understand the product in one screen, try it, install it from the Chrome Web Store. Proof: a working sample library (labelled sample) and real store screenshots. Constraints: self-contained static page (no external scripts, fonts or trackers), bundled Archivo, must describe the Google data use and link the privacy policy, Add to Chrome links to the store item laapaiiaipeoilipnbhpjmjbdkomhjln, Ko-fi link in the footer.

## Direction contract

THESIS: The page is one line. Every section is a stop on Linemark Orange, and the first stop is the product itself running live. It refuses the split hero (copy left, screenshot right, logo row, three feature cards).

OWN-WORLD: Wayfinding Lines unchanged: signage-black band with white semi-condensed Archivo labels, platform-white ground, Poster White sign and cards, round line bullets (letters or Lucide icons), the multi-line stripe under the station sign, hairlines, tabular figures, orange only for system and action.

STORY: A visitor reads "Bookmarks on lines.", plays with a real library (lines, icons, full-text search with snippets), rides the stops (save, find, keep healthy, private, Google account), and installs.

FIRST VIEWPORT: 1440x900. Left: 300px sticky black band, wordmark, the route (7 stops on a vertical orange line, current stop ringed), Add to Chrome pill at its foot. Right: station sign with 84px "Bookmarks on lines.", lede, Add to Chrome + Privacy policy, line-colour stripe; below it the live sample library (dark line list, search, 4-up cards) filling the rest.

FORM: The Route, rank 3 of 7 grounded structures; seed key cb3716df. Signature interaction: the ring rides the route as you scroll, and choosing a line in the demo sweeps the sign's stripe to that line's colour.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
